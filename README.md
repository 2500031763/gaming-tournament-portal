# 🎮 Gaming Tournament Portal

## 📌 Project Description

The Gaming Tournament Portal is a front-end web application designed to manage and participate in gaming tournaments. It provides separate interfaces for **Admin** and **Users**.

## 👥 Modules

### 🔐 Admin Module

* Admin Login
* Add tournaments
* Edit tournament details
* Delete tournaments
* View registered players
* Manage tournaments

### 👤 User Module

* User Registration/Login
* View available tournaments
* Register for tournaments
* View tournament details
* View registered tournaments

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎨 UI Design

The website uses:

* CSS Grid
* Flexbox
* Responsive design
* Interactive JavaScript components

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the Admin or User section to explore the application.
